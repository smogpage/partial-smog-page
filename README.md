# partial-smog-page.github.io
Backup smog-server page

This is a temporary posting of the smog-server webpage that is being used while we address a security issue. The webtools are not functional on this backup version, but all information is identical to that of the smog-server.org page. Only the webtools (i.e. .pl pages) are not included.

If you would like to view this page on your local machine, clone this repo and from within the root directory, you can launch a server with something like this:

python3.8 -m http.server
